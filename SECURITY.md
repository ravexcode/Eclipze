# Security Policy

## Supported Versions

Security fixes are considered for the latest code on the `master` branch.

## Reporting a Vulnerability

Do not report security vulnerabilities through public GitHub issues.

Send reports to [contact@ravexcode.com](mailto:contact@ravexcode.com). Include
a clear description, affected path or endpoint, reproduction steps, impact,
and any suggested mitigation. Do not include secrets, tokens, API keys, or user
data in the report.

## Scope

Reports are especially relevant when they affect authentication, sessions,
authorization or ownership of user data, API routes, Prisma/PostgreSQL data,
encrypted provider credentials, or the Gmail OAuth integration.
